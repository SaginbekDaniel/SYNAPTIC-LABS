### Проверенные механизмы и непройденные границы

- Базовый доступ gateway, `/healthz`, proxied API, health readiness, production build с CSP и отсутствие browser console errors проверялись пятью штатными smoke tests. Native Nginx использует исходный template с локальными путями и тестовым htpasswd. Контейнерный entrypoint, edge TLS/HSTS и forwarded-header trust во внешнем контуре не проверены.
- Код задаёт 21 MiB body limit в Nginx, 20 MiB в API, 200 000 строк и графовые caps. Подтверждён штатный 413 на малом искусственном лимите. Gateway rate limits заданы отдельно на reads/writes. Динамический rate-limit test и нагрузка TLS edge не запускались.
- SQL запросы в осмотренных путях работают через SQLAlchemy и параметризацию. LIKE-поиск экранирует wildcard. API проверяет UUID и схемы. React выводит case notes как text, штатный браузерный тест проверяет отсутствие диалога и ошибок страницы. Проверки не исчерпывают все входы SQL/XSS.
- CORS перечисляет origins и headers, cloud origins пустые в IaC. Cookie sessions приложения отсутствуют, gateway использует HTTP Basic. CSRF полного cloud окружения не проверялся. Для browser-auth writes нужен определённый session и same-origin/Origin design.
- CSV заголовки с дублями — подтверждённый риск целостности данных D01. В текущих endpoints нет CSV export, поэтому spreadsheet formula delivery неприменима. Upload имеет UTF-8/schema/row guards. Отдельного antivirus/DLP для банковского контура нет.
- Общий 500 envelope и validation details фильтруются, job failure summary образует отдельный канал S02. Поиск имён файлов по узкому набору high-signal secret signatures в HEAD не нашёл совпадений. История git и фактические секреты развёрнутого стенда не проверялись.
- PyPI scan проверил 29 runtime pins без известных advisories для них. Railway lockfile npm scan — 0. Bandit 1.9.4 проверил src/scripts, 18 LOW, 0 MEDIUM/HIGH. Среди LOW стандартные `assert`, `subprocess` в инструментах, non-cryptographic randomness в генераторах и строковые эвристики. Severity scanner не подтверждает эксплуатацию. [PyPI](evidence/pip-audit.json) · [Bandit](evidence/bandit.json) · [Railway npm](evidence/npm-audit-railway.json)
- LLM provider и prompts отсутствуют. Анализ transaction data не связан с исполнением перевода. Проверки реального BCC, Railway и сторонних приложений не выполнялись.

Повторная локальная проверка должна подтвердить модель прав на синтетических ролях, исправленные lockfiles и deployment preflight. Реестр различает severity, тип доказательства и статус. [Реестр](ISSUE_REGISTER.csv)
