**Amendment A2 (2026-11-22, metric arithmetic only).** All three artifacts were regenerated by their scripts after

## Reading the tables

* **Where the gain comes from.** `ablation_engine_without_gate` ≈ baseline: computing hypotheses alone
  changes nothing; the `benign_explanation_favoured → low` gate removes the recurring-business false
  positives (rent 18 → 0, marketplace 29 → 0, cash pooling 28 → 0, wholesale 16 → 0 of the sealed
  legitimate families) without any suspicious family losing a detection.
* **Recall +1.5 pp** is the funnel-v3 evasion fix (activation-payment collections 6/10 → 9/10).
* **Raw vs distinct P@5.** Raw P@5 overstates the candidate by 0.12 (0.713 vs 0.593) because duplicate
  alerts on one network count repeatedly (L-02). Distinct P@5 is the honest figure.
* **Boundary leak (L-01) quantified.** On `bench-v1` dev every abstention is planted fraud (1.000); on
  the label-blind sealed split 0.314. Any abstention-based `bench-v1` number is optimistic.
* **Abstention trade-off.** Without coverage abstention, sealed recall is 0.845 (vs 0.748) at FPR 0.181
  (vs 0.159): boundary centres would be flagged on structure alone. They are surfaced as
  `insufficient_evidence` instead (SX3 16/16 surfaced) — a deliberate choice not to overclaim.
* **Temporal evidence is load-bearing.** Without it recall falls to 0.534 and high-band recall to 0.073.

## Remaining risks

* Two independent groups are required for a benign verdict; an adversary controlling both recurrence
  and activity span (long-lived accounts with repeated small deposits) could still obtain one. Combined
  with F-06 this is the most important open detection risk.
* No real-data validation; no calibration (no independent labels exist).
* Authorization is absent (F-05).

What these numbers say and do not say:

* The v3-over-v2 improvement held on new data — mostly through fewer legitimate networks alerted (FPR
  0.485 → 0.254), with recall slightly up. It is still synthetic behaviour, not banking accuracy.
* The candidate's high-band FPR (0.208) is about twice its `sealed-v1` value: new legitimate lookalikes reach the top
  bands — payroll agency 25/25 flagged, event ticketing 32/42, group gift 20/29, property escrow 11/32 (identical for the
  baseline). Missed adversarial fraud: salary-like pass-through 0/17, recurring-feeder mules 1/12, boundary
  collection 0/17 flagged (by design it abstains; abstentions are not "flagged").
* `critical` is not more reliable than `high` here (4/10 vs 279/368), so the top band's ordering is not supported by
  this split.
* With label-blind boundaries, abstentions are no longer planted by construction: 34/166 abstention items are
  planted (on `bench-v1`, whose boundary list leaks labels, 8/8).
* These observations must **not** drive changes evaluated on `sealed-v2` again (protocol, "Use after the run"):
  improvements are developed on `bench-v1` dev (and an adversarial dev suite, B-045), frozen, then evaluated once.
